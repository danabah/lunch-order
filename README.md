# سامانه سفارش ناهار پرسنل (Corporate Lunch Order App)

یک اپلیکیشن بومی اندروید پیاده‌سازی شده با **Kotlin** و **Jetpack Compose / Material 3** جهت مدیریت و ثبت سفارش ناهار پرسنل بر اساس حضور یا عدم حضور.

## ویژگی‌ها و قابلیت‌ها:
1. **پنجره زمانی هوشمند و قابل تنظیم**:
   - پیش‌فرض: ثبت سفارش از ۲۴ ساعت قبل تا ساعت ۱۲:۰۰ ظهر همان روز باز است.
   - قفل خودکار ویرایش پس از گذشت مهلت قانونی (Cutoff).
   - نمایش وضعیت واضح مهلت ثبت سفارش به کاربر (فعال / منقضی شده / باز نشده).
2. **منوی غذای روزانه از پیش تعیین شده**:
   - نمایش نام غذا و مخلفات به ازای هر روز.
3. **اعلام وضعیت حضور / عدم حضور**:
   - کلیدهای اختصاصی «حاضر هستم (می‌خواهم)» و «غایب / عدم نیاز».
4. **بخش مدیریت (Admin Settings)**:
   - امکان تغییر ساعت مهلت سفارش و بازه زمانی باز بودن سفارش.
   - امکان ویرایش نام و مخلفات غذای روزها.
5. **رابط کاربری راست‌به‌چپ (RTL) و بومی‌سازی شده به زبان فارسی**.
6. **ذخیره‌سازی محلی (Local Persistence)** با SharedPreferences و ساختار JSON.

## نحوه اجرا در Android Studio:
1. پوشه `/mnt/data/lunch_order_app` را به عنوان یک پروژه موجود در **Android Studio** باز کنید (Open Project).
2. اجازه دهید Gradle فرآیند Sync و دانلود وابستگی‌ها را تکمیل کند.
3. برنامه را روی شبیه‌ساز (Emulator) یا دستگاه اندرویدی واقعی (Android 7.0 به بالا / API 24+) اجرا (Run) کنید.
